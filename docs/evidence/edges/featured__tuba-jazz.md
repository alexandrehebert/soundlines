# Tuba Jazz — instrument–genre association

Graph ID `featured:tuba-jazz`

**Review status** · Source checked (2026-11-05)

**Finding** · Sources place tuba in the bass role of early New Orleans jazz and dance bands; scholarship cautions against treating it as the only or universal early-jazz bass instrument. This edge is strongest for early jazz, before double bass became more common in many ensembles.
