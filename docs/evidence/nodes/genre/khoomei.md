## Assessment
The 1934 start marked documentation, not origin. All sources agree the practice is an old pastoral oral tradition but none dates it, so period.start is now circa 1800 as an explicit low-confidence placeholder (consistent with the Russian folk node's documentation-anchor convention). Phases: 1800 established (low), 1934 established (first recordings, medium), 1990 established at 0.6 intensity (international recognition, medium). No golden age is asserted. The description and phaseNote explain the placeholder.

## Remaining uncertainty
The true origin is undatable from available sources and could be centuries older than 1800. Earliest written (traveller/ethnographer) descriptions were not located.
