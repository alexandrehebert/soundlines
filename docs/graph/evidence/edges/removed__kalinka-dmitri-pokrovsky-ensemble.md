# Removed edge: Kalinka → Russian folk

Former graph ID `anthem:kalinka-russian-folk-dmitri-pokrovsky-ensemble`

**Disposition** · Removed (2026-11-05)

The edge asserted a particular Dmitri Pokrovsky Ensemble recording and its status as an anthem. The ensemble’s own press material and discography do not establish that version; one press text expressly cautions against expecting the ensemble to sing “Kalinka.” The [National Diet Library of Japan score record](https://enc.piano.or.jp/en/musics/79888) identifies the composed song, and [Library of Congress recordings](https://www.loc.gov/item/jukebox-248283/) provide historical performance context, but neither verifies this artist-specific edge.

The track node was renamed to generic `track:kalinka` and its description now identifies the composed Russian song without asserting an unverified performer. No genre-anthem relation is retained.
