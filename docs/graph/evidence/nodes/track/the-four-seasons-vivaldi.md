## Sources checked

- [Morgan Library & Museum — Il cimento, Op. 8](https://www.themorgan.org/music-manuscripts-and-printed-music/102126) — Catalogs first edition, ca. 1725, and identifies the first four concertos as The Four Seasons.
- [Bibliothèque nationale de France — Op. 8 catalog](https://catalogue.bnf.fr/ark:/12148/cb13917288t) — National library authority record dates the work to 1725 and lists Le quattro stagioni among its contents.
- [New Jersey Symphony — The Four Seasons](https://www.njsymphony.org/program_notes/detail/program-notes-vivaldis-the-four-seasons) — Orchestra notes explain the collection's publication and the four concertos' order.

## Assessment

1725 is the first-publication date, not a known composition date; changed description accordingly. Baroque classification is definitive. Removed the misleading recorded_by link to Vivaldi because this is a composition, not an identified performance.
