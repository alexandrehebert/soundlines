## Sources checked

## Assessment

1928 is well supported for composition and first performance, not first publication. BnF clarifies the work’s identity as an orchestral ballet, so the graph entry is a named composition rather than a particular recording.

## Remaining uncertainty

Different recording editions exist, but this node’s claim concerns Ravel’s composition and premiere.
