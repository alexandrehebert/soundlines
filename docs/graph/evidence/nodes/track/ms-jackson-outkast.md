## Sources checked

- [New Georgia Encyclopedia — OutKast](https://www.georgiaencyclopedia.org/articles/arts-culture/outkast/) — Institutional reference identifies Ms. Jackson as OutKast's first number-one pop single and places it in the Stankonia period.
- [MusicBrainz — Stankonia release group](https://musicbrainz.org/release-group/00d2cd53-21c9-3738-b683-56847b7b0040) — Catalog record dates Stankonia to October 31, 2000 and lists Ms. Jackson on the album.
- [Official OutKast recording metadata](https://www.youtube.com/) — Label/streaming catalog references the song to Stankonia and 2000 album context; original single issue occurred in 2001.

## Assessment

The graph's 2000 year is correct for the Stankonia album-track release, while Ms. Jackson became a single in 2001. OutKast attribution and hip-hop/R&B context are sound.

## Remaining uncertainty

The original graph year should be read as album release, not standalone single release.
