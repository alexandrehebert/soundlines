## Sources checked

- [CTM Festival artist biography](https://archive2013-2020.ctm-festival.de/archive/all-artists/p-t/squarepusher/) — Dates first use of the Squarepusher alias to the Conumber EP on Spymania in 1995.
- [DJ Mag, “Squarepusher Theme”](https://djmag.com/features/squarepusher-squarepusher-theme-game-changer) — Describes Conumber as the first release under the Squarepusher name.
- [AllMusic artist discography](https://www.allmusic.com/artist/squarepusher-mn0000004365) — Discography records early releases and the first Warp-era album.

## Assessment

Changed the broad circa-1994 onset to 1995, the date supported for first use of the Squarepusher alias. Earlier recordings under Tom Jenkinson’s name should not be conflated with the named project.
