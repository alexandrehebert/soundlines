# “Gasolina” enters the US Recording Registry

Graph ID `event:gasolina-recording-registry`

**Reviewed** · 2026-11-13

## Assessment

The Library of Congress selects Daddy Yankee’s 2004 recording for preservation. The Puerto Rican single helped carry reggaeton to a much wider international audience.

The timeline year refers to the documented registry selection, rather than the origin of the genre.
