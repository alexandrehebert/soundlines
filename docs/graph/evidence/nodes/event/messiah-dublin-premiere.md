# Handel’s Messiah premieres in Dublin

Graph ID `event:messiah-dublin-premiere`

**Review status** · reviewed

**Reviewed** · 2026-11-04

## Sources checked

- [Trinity College Dublin, Music in 18th-century Dublin](https://www.tcd.ie/library/exhibitions/in-tune/music_in_18thcentury_dublin.php) — Library exhibition identifies the first performance at Fishamble Street on 13 April 1742.
- [Handel and Haydn Society, Messiah program notes](https://handelandhaydn.org/enhanced-program-notes-handel-messiah/) — Historical notes confirm the Dublin premiere date and charitable concert context.

## Assessment

The public performance on 13 April 1742 is confirmed. Some sources distinguish the 9 April public rehearsal from the formal performance; the event’s premiere date is correctly 13 April.
