## Sources checked

- [IRCAM work catalog — In C](https://ressources.ircam.fr/en/work/in-c) — IRCAM catalogs In C as a 1964 work by Terry Riley and identifies 1964 as its composition date.
- [Library of Congress — National Recording Registry essay](https://www.loc.gov/static/programs/national-recording-preservation-board/documents/In-C_Carl.pdf) — Essay describes Riley composing the work in 1964 and the modular structure; it separately discusses the 1968 Columbia recording.
- [Juilliard — In C program note](https://www.juilliard.edu/sites/default/files/2.6_in_c_1.pdf) — Institutional program note dates the work's premiere to November 4, 1964.
- [Oxford Academic — Terry Riley's In C](https://academic.oup.com/book/1491) — Scholarly study distinguishes the 1964 San Francisco premiere from the 1968 Columbia recording.

## Assessment

The 1964 date is composition/premiere era, not a single identified studio recording. Changed the description from 'performed by' to 'composed by.' Existing graph relationship labeled recorded_by is unsupported for the work as a whole and has been removed; the graph edge vocabulary has no composed_by type. Minimalism is a well-established association.

## Remaining uncertainty

A later concrete performance/recording could be represented as a separate recording node; this entry currently denotes Riley's composition.
