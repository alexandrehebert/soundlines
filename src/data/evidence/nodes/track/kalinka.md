# Kalinka

Graph ID `track:kalinka`

**Review status** · Source checked at composition level, not as a particular recording

**Reviewed** · 2026-11-05

Russian song composed by Ivan Larionov around 1860, subsequently performed in folk and popular traditions. This graph node denotes the song generally; it does not assert a specific recording or performer.

Source checked: [PTNA Piano Encyclopedia](https://enc.piano.or.jp/en/musics/79888)
identifies Larionov's composition and the 1860 date. This is not a National Diet
Library catalog, as the earlier link label incorrectly claimed.

The [Library of Congress recording](https://www.loc.gov/item/jukebox-248283/)
remains an existing citation; it returned HTTP 403 in this follow-up and was not
used to establish any performer relationship.
