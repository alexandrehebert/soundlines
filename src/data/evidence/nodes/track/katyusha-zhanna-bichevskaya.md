## Sources checked

- [Presidential Library of Russia — Katyusha](https://www.prlib.ru/item/417603) — State library catalog credits music to Matvei Blanter, lyrics to Mikhail Isakovsky, and identifies a 1965 Melodiya recording/performance by Georgy Vinogradov.
- [Tatarstan Great Patriotic War Virtual Museum — Katyusha](https://tatfrontu.ru/news/katyusha-o-pesne-i-sudbe) — Museum account dates the song's first performance to November 28, 1938.
- [IMSLP — Katyusha score](https://imslp.org/wiki/Katyusha_(Blanter,_Matvey)) — Score catalog records the 1938 composition year and Isakovsky as librettist/lyricist.
- [Russian State Library — Zhanna Bichevskaya recording catalog](https://search.rsl.ru/ru/record/01007559492) — Catalog documents Bichevskaya recordings issued in 1990, but does not show that Katyusha is included.

## Assessment

1938 is supported as the composition/first-performance year, not as the date of a Zhanna Bichevskaya recording. Corrected the description to make the year refer to the song itself. No evidence found linking this specific version to Bichevskaya, so the unsupported recorded_by edge was removed.

## Remaining uncertainty

The recording/version attribution remains unresolved. The legacy ID retains Bichevskaya for stability; add an artist edge only if an identifiable release/audio source confirms it.
