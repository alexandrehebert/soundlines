## Sources checked

- [Cheb Mami profile, Encyclopedia.com](https://www.encyclopedia.com/people/literature-and-arts/music-popular-and-jazz-biographies/cheb-mami) — Chronology records a radio contest in 1982, first public performance at Oran’s raï festival in 1985, and 1989 album.
- [Cheb Mami biography, AllMusic](https://www.allmusic.com/artist/cheb-mami-mn0000106000) — Identifies 1989 as the first internationally distributed album, distinguishing it from earlier local career activity.
- [Taratata artist biography](https://mytaratata.com/artistes/cheb-mami) — Dates first official public appearance to the 1985 Oran Raï Festival and debut album to 1986.

## Assessment

Retained 1982 as the earliest documented professional marker (radio contest), rather than 1985 public festival debut or the 1989 international album. The three sources differ on first album release year, so the description avoids asserting it.

## Remaining uncertainty

Local album/cassette release chronology before international distribution remains inconsistent across references.
