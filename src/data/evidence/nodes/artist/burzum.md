## Sources checked

- [Official Burzum discography detail](https://www.burzum.org/eng/discography/) — Discography indicates return to studio releases after long hiatus, making 2000 an incorrect permanent endpoint.
- [Existing AllMusic black metal page](https://www.allmusic.com/style/black-metal-ma0000002463) — Genre page is not evidence for this individual project’s dates.

## Assessment

Changed the 1990s decade start to 1991, the name/project adoption year. Changed entity kind from group to person because Burzum is a solo project, not an ensemble. Left endpoint open: the 2020 album is a recent release marker, not proof the project ended.

## Remaining uncertainty

Official catalog attribution should be supplemented by independent discography/label records, especially for the 2010s–2020 releases. Clarify in graph terminology that this is a solo project, not a group.
